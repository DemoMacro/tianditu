---
title: 密钥（tk）
description: 浏览器端密钥与服务器端密钥的区别与申请
---

调用天地图服务要有开发者密钥（tk）。密钥分两种，用途不一样：**本站所有示例都要你自己输入密钥才能运行**，密钥只存在你的浏览器 localStorage 里，不会上传。

## 两类密钥

| | 浏览器端密钥 | 服务器端密钥 |
| --- | --- | --- |
| 用途 | 地图 JS API 的地图展示（加载底图瓦片、覆盖物、控件等） | REST 服务接口（地名搜索、地理编码、行政区查询等） |
| 使用位置 | 浏览器 | 服务端或浏览器直连 |
| 对应包 | `@tianditu/vue`、`@tianditu/web-components`、`@tianditu/core` | `@tianditu/services` |

::caution
两类密钥不能混用：拿服务器端密钥加载地图会失败，拿浏览器端密钥调部分服务接口会被拒。按实际用途分别申请即可。
::

## 申请

在天地图[控制台](https://console.tianditu.gov.cn/api/key)申请，按用途选浏览器端或服务器端类型。

## 在本站使用

- **地图类示例**（如[第一个地图](/getting-started/first-map)）：输入**浏览器端密钥**，地图马上渲染，刷新后也不用重输。
- **服务类示例**（如 [REST 服务](/services/rest)）：输入**服务器端密钥**就能直接搜索。

部署文档站时也可以不输入，改用环境变量注入默认值：

```bash
NUXT_PUBLIC_TIANDITU_BROWSER_KEY=你的浏览器端密钥
NUXT_PUBLIC_TIANDITU_SERVER_KEY=你的服务器端密钥
```
