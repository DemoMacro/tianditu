对照官方标绘（plotSymbols）文档实现的三组能力：标号实体（覆盖物组件）、标绘工具（`*Tool` 组件）与标绘控件。均须写在 `<TdtMap>` 内部。

:::DemoMap
<tdt-straight-arrow :path="[[116.37, 39.89], [116.41, 39.93]]" color="#dc2626" />
<tdt-control-plot-symbols position="topleft" />
:::

地图左侧是标绘控件面板，可以交互绘制标号；地图上是一条静态绘制的箭头。

## 标号实体

22 个标号实体的统一 props 为 `path`（关键点坐标数组）与线、填充样式。下列说明与官方文档逐类对应。

### tdt-arc

此类用来表示地图上构造一个弧线的覆盖物类。

:::demo-tabs

```vue [Vue]
<TdtArc :path="[[116.37, 39.89], [116.41, 39.93]]" />
```

```html [Web Components]
<tdt-arc path="116.37,39.89;116.41,39.93"></tdt-arc>
```

```tsx [React]
<TdtArc path={[[116.37, 39.89], [116.41, 39.93]]} />
```

:::

构造：`Arc(points:Array<LngLat>,opts:CardinalCurveOptions)`

构造参数（官方 Options）：

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| color | string | "#0000FF" | 弧线的线颜色。 |
| weight | number | 3 | 弧线的宽度，以像素为单位。 |
| opacity | number | 0.5 | 弧线的透明度（范围0-1 之间）。 |
| lineStyle | string | "solid" | 弧线的线样式（solid或dashed）。 |

| 方法 | 返回值 | 说明 |
| --- | --- | --- |
| setLngLats(lnglats:Array&lt;LngLat&gt;) | none | 设置弧线的点数组。 |
| getLngLats() | Array&lt;LngLat&gt; | 返回弧线的控制点数组。 |

```vue
<tdt-control-plot-symbols position="topleft" />
```

| 方法 | 返回值 | 说明 |
| --- | --- | --- |
| clearLayers() | null | 清空控件所有绘制的。 |
| getLayers() | Array&lt;Layer&gt; | 获取控件所有绘制的图形。 |
| Close() | null | 关闭并清空当前绘制的图形。 |
