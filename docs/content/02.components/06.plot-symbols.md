对照官方标绘（plotSymbols）文档实现的三组能力：标号实体（覆盖物组件）、标绘工具（`*Tool` 组件）与标绘控件。均须写在 `<TdtMap>` 内部。

## 标号实体

22 个标号实体组件，props 统一为 `path`（坐标数组，必填）加线样式：

```vue
<TdtStraightArrow :path="[[116.38, 39.9], [116.42, 39.93]]" color="#dc2626" />
<TdtDoubleArrow :path="p1" fill-color="#dc2626" :fill-opacity="0.4" />
```

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `path` | `Array<[number, number] \| LngLat>` | 标号位置的关键点坐标（必填） |
| `color` / `weight` / `opacity` / `lineStyle` | — | 线样式（`lineStyle` 为 `"solid" \| "dashed"`） |
| `fillColor` / `fillOpacity` | — | 填充样式 |

::note
标号实体仅暴露 `setLngLats`/`getLngLats`，线样式 props 仅构造时生效。
::

实体组件清单：

`TdtArc` `TdtBezierCurve2` `TdtBezierCurve3` `TdtBezierCurveArrow` `TdtBezierCurveN` `TdtCardinalCurve` `TdtCardinalCurveArrow` `TdtCloseCurve` `TdtCurveFlag` `TdtDiagonalArrow` `TdtDoubleArrow` `TdtDoveTailDiagonalArrow` `TdtDoveTailStraightArrow` `TdtGatheringPlace` `TdtParallelSearch` `TdtPolylineArrow` `TdtRectFlag` `TdtRoundRect` `TdtSector` `TdtSectorSearch` `TdtStraightArrow` `TdtTriangleFlag`

## 标绘工具

23 个标绘工具，交互绘制对应标号；受控 `active` 开关，`style` 为统一的线/面样式：

```vue
<TdtStraightArrowTool :active="active" :style="{ color: '#dc2626' }" @draw="(e) => console.log(e)" />
```

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `active` | `boolean` | 受控开关 |
| `style` | `object` | 标号样式 |
| `layers` | `LayerGroup` | 绘制结果放入指定图层组（可选） |

工具组件清单（与实体一一对应，另含自由绘制）：

`TdtArcTool` `TdtBezierCurve2Tool` `TdtBezierCurve3Tool` `TdtBezierCurveArrowTool` `TdtBezierCurveNTool` `TdtCardinalCurveArrowTool` `TdtCardinalCurveTool` `TdtCloseCurveTool` `TdtCurveFlagTool` `TdtDiagonalArrowTool` `TdtDoubleArrowTool` `TdtDoveTailDiagonalArrowTool` `TdtDoveTailStraightArrowTool` `TdtGatheringPlaceTool` `TdtHandDrawingTool` `TdtParallelSearchTool` `TdtPolylineArrowTool` `TdtRectFlagTool` `TdtRoundRectTool` `TdtSectorSearchTool` `TdtSectorTool` `TdtStraightArrowTool` `TdtTriangleFlagTool`

## 标绘控件

官方以地图控件形态提供的标绘面板，按钮驱动全部标号绘制：

```vue
<TdtControlPlotSymbols position="topleft" />
```

## 完整示例

```vue
<template>
  <TdtMap tk="浏览器端密钥" :center="[116.404, 39.915]" :zoom="10">
    <TdtControlPlotSymbols position="topleft" />
    <TdtStraightArrow :path="path" color="#dc2626" />
  </TdtMap>
</template>
```
